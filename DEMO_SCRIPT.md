# BreatheWise AI — 3-minute demo script

## Before recording

Start the app from `A:\air aws` with `pnpm.cmd dev`. Use the deployed AWS Amplify URL if it is ready; otherwise use `http://localhost:5173` for practice. Close unrelated windows and keep the browser signed out.

## Recording flow

**0:00–0:20 — Problem and audience**

“BreatheWise helps people turn live air-quality data into a safer plan for the day. It is designed for commuters, children, people with respiratory conditions, and outdoor workers.”

**0:20–0:50 — Live location and current data**

Search for a city. Select the correct result with its state/country shown. Point out the current US AQI, the weather, PM2.5, PM10, ozone, NO₂, source, and update time.

**0:50–1:25 — Personal planner**

Select “Asthma / COPD”, “Run / intense exercise”, and “30 minutes”. Show how the recommendation changes. Switch to “General public” to show the personalized result changing.

**1:25–1:50 — Plan ahead and protect indoor air**

Scroll through the next-24-hour forecast. Explain that users can choose a cleaner window. Show the indoor-air guidance for high pollution days.

**1:50–2:15 — Compare and understand**

Compare another city. Ask the BreatheWise helper: “Can I run outside?” Show the answer grounded in the current AQI. Open the map link if time allows.

**2:15–2:35 — Alerts and reliability**

Show the browser-alert toggle, the visible source/timestamp, and the retry state or explain that the app keeps errors visible instead of hiding stale data.

**2:35–3:00 — AWS and close**

Show the AWS Amplify deployment URL and the public repository. Say: “The frontend is hosted on AWS Amplify. The app uses public Open-Meteo APIs without exposing secrets. The project was built with React, TypeScript, Vite, and Codex.”
